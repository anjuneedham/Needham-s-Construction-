don't waste a trip re-shooting what's already covered.

is fine), phone camera quality is fine. No need for a professional shoot —
the site treats every photo as real documentation of the work, not styled
marketing.

## Bonus — not required, but valuable if easy to get

- **Before-and-after pairs of the same job.** Everything on the site right
  now is a single "after" (or "in progress") shot. Even one true before/after
  pair — same angle, same spot, before work started and after it finished —
  is one of the strongest things a small contractor site can show.
- **A crew photo** — anyone actually working on site. Humanizes the "About"
  page and is good for social media, which has no photos yet either.
- Wide site/progress shots even if not a finished result — useful for
  Instagram/Facebook posts later, not just the website.
